# 白领求职捷径
一键直达公司员工内推帖子，认识目标公司里的人脉。输入目标岗位、公司、城市或薪资（比如“上海 后端 3w”），即可获得按公司整理的「内推＋人脉+岗位」清单，并在最后查看专业技能关键词。

完整技能包包含技能说明、参考文档、HTML 模板、二维码图片和本地渲染脚本。

## 可以获得什么
清单按公司聚合，依次展示：
- 公司内推入口：优先寻找有明确内推意愿的帖子，发现企业不公开的工作机会
- 公司人脉入口：每家公司提供“去获取该公司人脉”，进入脉脉以该公司名称为关键词的搜索找人页。
- 关联岗位：作为补充，展示经详情页核验的岗位、薪资、城市和职位描述与要求。暂时找不到岗位，也会保留有价值的内推与人脉。
- 专业技能词：从本次已核验的岗位样本提取技能 TOP10，排除责任心、抗压性等软技能，统一放在清单最后
- 优先扩大大厂与明星公司覆盖，再补充每家公司的线索。


## 使用前提

请先确认运行技能的 Agent 宿主支持导入该技能包，并具备可用的浏览器工具：

- **优先使用内置浏览器**：宿主能自行打开、操作、读取页面并复用登录会话时，直接使用。
- **内置能力不足时，沿用用户的宿主设置**：使用已配置的浏览器自动化技能、浏览器 MCP、扩展或 CDP 工具；不固定为 Chrome 或 Edge。宿主设置为系统默认浏览器时，使用该用户的实际默认浏览器。
- 用户在选定的可控浏览器会话中登录脉脉，之后复用同一会话。仅能打开网址，不等于能够读取登录后的页面；缺少控制或读取能力时会说明具体缺口。
- 优先后台查询，隐藏、后台标签或可见执行遵循宿主能力及用户设置；用户明确要求完全隐藏而当前工具无法满足时，保留进度并说明限制。
- 宿主支持生成并输出文件，以便交付 HTML 清单。

具体规则见[浏览器选择、登录与后台执行](maimai-career-shortcut/references/browser-adaptation.md)。已有配置可用时直接执行，不重复要求安装或选择浏览器；没有可用工具时，引导用户在宿主中配置。

各宿主的导入、控制、会话复用和文件输出能力需要分别验证。技能包不附带登录会话、浏览器连接器或岗位数据库，不因安装成功就宣称跨平台实机适配完成。

## 提问示例
- “帮我找字节跳动的内推。”
- “上海算法岗位，月薪上限大于 35k，优先大厂。”
- “北京前端，帮我整理公司内推入口和关联岗位。”
目标岗位、公司、城市、薪资可任选一项或多项；简历不是必填项。

本技能不保证获得内推或录用，不自动发消息、加好友、请求内推或投递。岗位状态、内推意愿与站内访问权限以脉脉及相关方确认结果为准。
