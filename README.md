# 白领求职捷径

根据目标岗位、公司、城市或薪资，在脉脉查找内推线索，按公司整理求职机会清单。

## 下载与入口

- [下载完整技能包](白领求职捷径-skill.zip)
- [查看技能说明](maimai-career-shortcut/SKILL.md)
- [查看技能目录](maimai-career-shortcut/)

完整技能包包含技能说明、参考文档、HTML 模板、二维码图片和本地渲染脚本。

## 可以获得什么

清单按公司聚合，依次展示：

1. 已核验原文的内推帖子及原帖链接。
2. 以公司名称为关键词的脉脉站内找人入口。
3. 符合本次条件、已核验详情的关联岗位。
4. 全部公司卡片之后的岗位样本专业技能 TOP10。

公司找人入口不表示已找到具体员工，也不代表对方承诺内推。技能统计仅来自本次读取的岗位样本；样本不足时不生成排名。

## 使用前提

请先确认运行技能的 Agent 宿主支持导入该技能包，并具备以下能力：

- 可由 Agent 控制的内置浏览器。
- 用户在该浏览器登录脉脉后，可复用同一登录会话读取页面。
- 搜索与详情核验可使用隐藏研究页面；仅不抢焦点或最小化不等于隐藏。
- 支持生成并输出文件，以便交付 HTML 清单。

各宿主的导入方式与浏览器能力需要分别验证，不能保证跨平台兼容。技能包不附带登录会话、浏览器连接器或岗位数据库；缺少必要能力时会说明限制并保留已有进度。

## 提问示例

- “帮我找字节跳动的内推。”
- “上海算法岗位，月薪上限大于 35k，优先大厂。”
- “北京前端，帮我整理公司内推入口和关联岗位。”

目标岗位、公司、城市、薪资可任选一项或多项；简历不是必填项。

本技能不保证获得内推或录用，不自动发消息、加好友、请求内推或投递。岗位状态、内推意愿与站内访问权限以脉脉及相关方确认结果为准。
